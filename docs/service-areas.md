# Greater Houston service areas

The homepage and directory cover Greater Houston from Galveston to Magnolia and Kingwood to Richmond, including the surrounding communities listed in the site data. Eight individually written guides serve Houston, Katy, Sugar Land, The Woodlands, Kingwood, Richmond, Galveston and Magnolia. Each guide includes practical project planning advice, relevant services, portfolio references, nearby guides, questions and a quote CTA.

The pages use the existing prerendering pipeline, unique metadata, canonical URLs and visible breadcrumbs. The sitemap includes all eight guides. Service coverage does not imply a local office or attribute an existing portfolio project to a city. Business structured data omits an unverified physical address.

Run `npm run check:service-areas` and `npm run check:seo` to check content, routes, metadata, links and structured data without running a build.
