# Houston SEO implementation

Houston, Texas is the primary target, with dedicated service guides for eight Greater Houston locations. Page titles, descriptions, service content and internal links focus on custom woodworking, furniture, wood furniture, cabinets, epoxy tables, live-edge dining tables, retail display cabinets and custom jewelry workbenches. Keywords are used in context rather than repeated as lists in page metadata.

All 24 indexable routes have distinct titles and descriptions, one H1, canonical URLs and structured data. Internal pages include visible breadcrumbs. The sitemap is maintained in public assets and regenerated from the route registry during the existing build pipeline. Robots.txt links to it. Portfolio content retains the six real projects, without inventing local installations or reviews.

Existing Netlify Image CDN delivery provides responsive, negotiated modern image formats. Below-the-fold images load lazily. Core Web Vitals and search ranking improvements require measurement on a deployed site; no ranking or performance score is asserted by these changes.
